# Kigali HomeTech RAG Chatbot

This repository contains a small learning project for a customer-support chatbot that answers from approved Kigali HomeTech Store documents and displays its sources.

## Project folders

- `rag-based-chatbot/` - document ingestion, ChromaDB, retrieval, LLM API calls, and the backend API
- `frontend/` - the customer chat interface

The project is intentionally small so beginners can understand the complete RAG process.
